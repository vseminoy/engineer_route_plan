# Интеллектуальный сервис планирования маршрутов выездных инженеров

Комплект документации к кейсу «Билайн Бизнес» (хакатон). Составлено на основе:

- `docs/technical_specifications.pdf` — постановка задачи организатора;
- `docs/conditions.md` — 45 уточняющих условий (FAQ) от организатора;
- `docs/Нормативы.xlsx` — нормативы длительности работ по видам заявок;
- `docs/ideas.md` — обзор подходов (VRPTW, STRSPTW, биоинспирированные алгоритмы);
- `docs/application.md` — заявка команды на участие;
- `docs/synthetic_data/*.csv`, `docs/control_distribution/*.csv` — примеры данных по трём регионам (Восток, Юго-Восток, Югоцентр).

## Как читать комплект

1. Документы 1–2 — для защиты подхода перед жюри и синхронизации команды (что делаем и почему).
2. Документы 3–4 — постановка задачи для разработчиков бэкенда/фронтенда уровня «что нужно реализовать и зачем».
3. Документы 5–6 — исполняемая спецификация уровня «как именно реализовать» (схемы, контракты, типы).
4. Документ 7 — рабочая шпаргалка по реальным полям и значениям из выданных данных.

Все документы согласованы между собой по терминологии и идентификаторам требований (`FR-xx`, `NFR-xx`, `BR-xx`).
